# ENGORA - Engineering Student OS 

نظام متكامل وخفيف لطلاب الهندسة لإدارة وتتبع المواد، المواضيع، المهام، والتقييمات.

##  المميزات
- **إدارة المواد والمواضيع**: تتبع نسبة الإنجاز والتقدم في كل مادة دراسية.
- **تتبع المهام والمراجعات**: تنظيم المذاكرة والمراجعات بسهولة.
- **نظام النسخ الاحتياطي (Backup & Restore)**: حفظ واسترجاع البيانات بضغطة زر.
- **واجهة مستخدم حديثة وتفاعلية**: دعم الوضع الليلي والنهاري (Dark/Light Mode) وتصميم متجاوب للهواتف والأجهزة المحمولة.

##  كيفية التشغيل
لا يحتاج التطبيق إلى تثبيت أي مكتبات أو سيرفر معقد، فقط افتح ملف `index.html` في أي متصفح!

أو يمكنك تشغيله باستخدام سيرفر محلي بسيط:
```bash
python3 -m http.server 8080
```
ثم افتح المتصفح على: `http://localhost:8080`
