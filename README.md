# 🎓 ENGORA — Engineering Student OS

نظام متكامل وخفيف مصمم خصيصاً لطلاب كليات الهندسة لإدارة المواد الدراسية، متابعة التقدم، وتحليل المحاضرات والمسائل باستخدام الذكاء الاصطناعي (Google Gemini).

---

## ⚡ المميزات الرئيسية

1. **تحليل المحاضرات بالذكاء الاصطناعي**:
   - دعم رفع ملفات **PDF، PowerPoint (pptx)، Word (docx)** أو لصق النص مباشرة.
   - استخراج وتلخيص أهم المفاهيم والقوانين الهندسية والصور/المخططات التوضيحية.
   - إنشاء كويزات تفاعلية تلقائياً لاختبار الفهم وتثبيت المعلومة.

2. **شرح المسائل خطوة بخطوة (Socratic Tutor)**:
   - حل المسائل بطريقة تفاعلية تعتمد على توجيه الطالب للحل بدلاً من إعطائه الإجابة الجاهزة.
   - إمكانية رفع صورة للمسألة أو كتابة نصها، مع دعم الشرح بالعامية المصرية المبسطة.

3. **مراجعة شيتات الرسم الهندسي (Engineering Drawing)**:
   - مراجعة أولية لصور شيتات الرسم الهندسي للتحقق من جودة الإسقاط، الأبعاد، وتناسق الخطوط.

4. **خريطة المعرفة ومتابعة الأداء (Spaced Repetition)**:
   - توزيع ومتابعة جلسات المذاكرة حسب مستوى إتقان كل موضوع.
   - تنبيهات ذكية للمواضيع التي تحتاج لمراجعة سريعة.

5. **النسخ الاحتياطي والخصوصية**:
   - حفظ البيانات محلياً بنسبة 100% على جهازك عبر المتصفح (LocalStorage).
   - إمكانية تصدير واسترجاع نسخة احتياطية كاملة (Backup & Restore) بملف JSON في أي وقت.
   - دعم الوضعين الليلي والنهاري (Dark & Light Mode).

## 🔑 كيفية الحصول على مفتاح Gemini API مجاناً

التطبيق يستخدم نماذج **Google Gemini** السريعة والمجانية. للحصول على مفتاحك الخاص:

1. ادخل مباشرة على الرابط التالي في **Google AI Studio**:  
   👉 **[https://aistudio.google.com/app/apikey?.com](https://aistudio.google.com/app/apikey?.com)**
2. سجّل الدخول بحساب Google الخاص بك.
3. اضغط على زر **Create API Key** (إنشاء مفتاح API).
4. اختر مشروعاً موجوداً أو اضغط **Create key in new project**.
5. انسخ المفتاح الذي يظهر لك (المفتاح مجاني بالكامل للاستخدام الشخصي).

---

## ⚙️ كيفية إدخال المفتاح في التطبيق

يمكنك ربط مفتاحك بإحدى الطريقتين:

### الطريقة الأولى (الأسهل والموصى بها - من داخل المتصفح):
1. افتح صفحة التطبيق في المتصفح.
2. اضغط على أيقونة الروبوت **🤖** الموجودة في أعلى الشاشة جهة اليسار.
3. الصق المفتاح في الخانة واضغط **حفظ المفتاح**.
4. سيتم حفظ المفتاح بأمان داخل متصفحك الشخصي فقط ولن يخرج منه.

---

### الطريقة الثانية (عبر ملف الإعدادات المحلي `env.js`):
إذا كنت تفضل تجهيز المفتاح مباشرة في ملفات المشروع:
1. انسخ ملف `env.example.js` وأعد تسميته إلى `env.js`:
   ```bash
   cp env.example.js env.js
   ```
2. افتح ملف `env.js` وضع مفتاحك بداخله:
   ```javascript
   window.ENGORA_ENV = {
     GEMINI_API_KEY: "ضع_مفتاحك_هنا"
   };
   ```
> 🛡️ **ملاحظة أمان هامة**: تم تضمين ملفات `env.js` وجميع ملفات `.env` داخل ملف `.gitignore`، وبالتالي لن يتم رفع مفتاحك السري إطلاقاً عند عمل `git push` إلى GitHub أو أي مستودع عام.

## 🚀 كيفية التشغيل

لا تحتاج لتثبيت أي سيرفرات أو مكتبات معقدة؛ التطبيق يعمل كصفحة واحدة مستقلة (Standalone):

- **الطريقة المباشرة**: اضغط نقرتين على ملف `index.html` ليفتح في أي متصفح حديث (Chrome / Edge / Firefox / Safari).
- **أو عبر سيرفر محلي خفيف**:
  ```bash
  # باستخدام بايثون:
  python -m http.server 8080

  # أو باستخدام Node.js:
  npx serve .
  ```
  ثم افتح الرابط: `http://localhost:8080` في متصفحك.
